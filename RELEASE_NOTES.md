# Release notes

## 1.0.0-beta — GitHub APK handoff
- Finalized the Android source handoff with app title `MR91 Journal`.
- Added a custom launcher icon and version metadata.
- Added GitHub Actions workflow to build and upload a downloadable debug APK.
- Added `.gitignore` rules to keep local build files and signing secrets out of Git.
- Expanded documentation with exact GitHub steps for obtaining the APK.

## Existing application features
- Offline SQLite trade journal with create/edit/delete.
- Trade screenshots stored locally in app-private storage.
- Dashboard metrics and strategy breakdown.
- Search and date filters.
- PDF/CSV/JSON export and ZIP backup/restore.
